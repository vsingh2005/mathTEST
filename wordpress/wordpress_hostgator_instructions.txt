1. HOW TO IMPORT ALL CHANGES TO YOUR OFFICIAL WEBSITE (HOSTGATOR & WORDPRESS)
--------------------------------------------------------------------------------

Step 1: Upload the Plugin to HostGator
--------------------------------------
1. Log in to your HostGator cPanel (https://yourdomain.com:2083).
2. Open File Manager and navigate to public_html/wp-content/plugins/.
3. Create a directory named "kss-math-portal".
4. Upload "wordpress/kss-math-portal.php" into public_html/wp-content/plugins/kss-math-portal/.

Step 2: Upload Web App Assets
-----------------------------
1. Inside public_html/wp-content/plugins/kss-math-portal/, create a folder named "assets".
2. Upload all files from your repository's "website/" directory into public_html/wp-content/plugins/kss-math-portal/assets/:
   - login.html
   - portal.html
   - instructions.html
   - exam.html
   - results.html
   - practice.html
   - sound.js
   - auth.js
   - app.js
   - index.css
   - hero_kids_math_classroom_1783004330739.png
   - success_celebration_illustration_1782954288674.png
   - kss.png
   - pages/ (modular multi-page application subfolders: login, portal, exam, results, practice)
   - shared/ (shared css, js, and curriculum data files)

Step 3: Activate Plugin in WordPress Dashboard
----------------------------------------------
1. Log in to your WordPress Admin Panel (https://yourdomain.com/wp-admin).
2. Go to Plugins -> Installed Plugins.
3. Locate "KSS Math Portal & Question Bank Manager" and click Activate.

Step 4: Add Pages in Elementor
------------------------------
Create or edit your pages in Elementor and use the shortcodes:
- Login Page:                     [kss_math_login]
- Portal Dashboard & Tracks:      [kss_math_portal]
- Instructions Page:              [kss_math_instructions]
- Exam Engine Page:               [kss_math_exam]
- Results & Breakdown Page:       [kss_math_results]
- Digital Practice Worksheets:    [kss_math_practice]

(Alternatively, embed via an Elementor HTML iframe widget:
<iframe src="/wp-content/plugins/kss-math-portal/assets/login.html" style="width:100%; height:850px; border:none;"></iframe>)

2. ALL SETTINGS AVAILABLE IN THE WORDPRESS ADMIN DASHBOARD
================================================================================

When you open WordPress Admin Dashboard -> Math Portal 🧮, you have two main control tabs:

Tab 1: Color Customizer & Exam Settings
---------------------------------------
- Primary Accent Color Picker: Custom hex color picker for active timeline steps, links, and main headers (Default: #4DA8FF).
- Secondary Accent Color Picker: Custom hex color picker for recommendations and score badges (Default: #5ECF7A).
- Brand Button Color Picker: Custom hex color picker for action button gradients (Default: #2fbdb9).
- Header & Dark Theme Color Picker: Custom hex color picker for main typography, login background, and footer (Default: #263238).
- 5 Quick Theme Presets: Dropdown to instantly apply pre-designed color themes with one click:
  1. Kids STEM Studio Classic (Sky Blue & Teal)
  2. Modern Indigo & Violet
  3. Emerald & Mint Energy
  4. Warm Sunset (Coral & Amber)
  5. Sleek Dark Mode Accent
- Questions Per Exam: Number input (5 to 50 questions) to adjust test length.
- Countdown / Elapsed Timer: Checkbox to display or hide the live timer during tests.
- Enabled Test Tracks: Checkboxes to individually enable/disable test tracks (Grades 3–4, Grades 5–6, Grades 7–8).
- Instant Results & Solutions: Checkbox to toggle whether students see detailed score breakdowns & step-by-step solutions immediately upon completing a test.

Tab 2: Question Bank Manager
----------------------------
- Question Bank Table: View all active questions with ID, Grade (3–8), Topic/Domain, Text, and Type.
- Add New Question: Form to add custom questions (Multiple Choice or Numeric Response), set options, select the correct answer, and write step-by-step solution explanations.
- Edit Questions: Edit any existing question's text, options, grade, or explanation.
- Delete Questions: Remove questions from the question pool.
- Reset to Default Bank: Restore the baseline question pool with a single click.

Tab 3: Student Progress & Mastery Reports
-----------------------------------------
- View student diagnostic placement results, placed grade levels, and completed worksheets.
- Real-time stars earned (⭐⭐⭐), current and max streaks (🔥), and unlocked curriculum lessons.
- Individual student breakdown by user ID, student name, and last activity timestamp.
- Synchronized with POST /wp-json/kss-math/v1/student-progress.

================================================================================
Note: Whenever an administrator saves changes in the WordPress Dashboard, the REST API
(/wp-json/kss-math/v1/settings and /wp-json/kss-math/v1/questions) dynamically updates
the live portal for all students!
